# Material library (`.MDB`)

Source: `GolDP.dll`. Read with the token reader (`token-reader.md`). The English `LEGO.JAM` holds 208 `.MDB` files; all parse and end exactly at their last byte.

| Address      | Role                                                                                                                                                                              |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `0x10026270` | Loader (material library vtable `0x10057134` `+0x24`); jump tables `0x100268ec`/`0x10026898`, `0x10026918`, `0x10026938`                                                          |
| `0x10028250` | Allocates the name table (count × 12 bytes)                                                                                                                                       |
| `0x100282c0` | Adds a name: hash over ≤ 8 chars, `strncmp(…, 8)`; equal name → `<name>: Duplicate name encountered` (fatal)                                                                      |
| `0x10028b90` | Texture lookup; failure → `Mat def file references unknown texture: <name>` (fatal)                                                                                               |
| `0x100257e0` | Copies the definition into the material (`+8` flags, `+0x10` ambient, `+0xc` diffuse, `+0x20..0x23` bytes, `+4` texture if flag 8), with texture-dependent overrides (not ported) |
| `0x1000a2c0` | Renderer applying a material (D3D render and texture-stage states); source of the meanings below                                                                                  |

## Layout

```
0x27 [ count ] {            count = 0 → error 4
  ( 0x27 "name" {  keyword…  } ) × count      name ≤ 8 chars (else error 14)
}                                              nothing after this is read
```

Each material starts from: flags `0x0050a694`, texture none, ambient and diffuse `ff ff ff ff`, alpha function 2, alpha reference 0, source blend 1, destination blend/opacity 0. Keywords until `}`:

| Token                                  | Operands                | Effect (flags: clear / set)             | Meaning in `0x1000a2c0`                                                                                                                                                                                                                                               |
| -------------------------------------- | ----------------------- | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `0x28`                                 | 4 ints (bytes)          | ambient color                           | scaled by the ambient light; 4th byte is alpha                                                                                                                                                                                                                        |
| `0x29`                                 | 4 ints (bytes)          | diffuse color                           | scaled by each light                                                                                                                                                                                                                                                  |
| `0x2a`                                 | —                       | `4` / `2`                               | flat shading (`SHADEMODE` 1)                                                                                                                                                                                                                                          |
| `0x2b`                                 | —                       | `2` / `4`                               | Gouraud shading                                                                                                                                                                                                                                                       |
| `0x2c`                                 | string ≤ 8              | texture name; set `8`                   | textured                                                                                                                                                                                                                                                              |
| `0x2d`                                 | —                       | `0x10` / `0x20`                         | texture × color (`COLOROP` MODULATE)                                                                                                                                                                                                                                  |
| `0x2e`                                 | —                       | `0x20` / `0x10`                         | texture only (`COLOROP` SELECTARG1)                                                                                                                                                                                                                                   |
| `0x2f`                                 | function token, ref     | `0x80` / `0x40`                         | alpha test; `0x30`..`0x37` → function 0..7 (`0x10056540`: ALWAYS, EQUAL, GREATER, GREATEREQUAL, LESS, LESSEQUAL, NEVER, NOTEQUAL); `0x30` and `0x36` take no reference; any other token is dropped and a reference is read if the current function is neither 0 nor 6 |
| `0x38`                                 | 2 tokens `0x39`..`0x43` | `0x1200` / `0x2100`                     | blending; source and destination factor 0..10; other token → error 19                                                                                                                                                                                                 |
| `0x44`                                 | —                       | `0x800` / `0x400`                       | linear filtering (if supported)                                                                                                                                                                                                                                       |
| `0x45`                                 | —                       | `0x400` / `0x800`                       | point filtering                                                                                                                                                                                                                                                       |
| `0x46`, `0x4d`, `0x4e`, `0x4f`, `0x50` | int                     | `0x2100` / `0x1200`; byte `+0x23` = int | constant opacity                                                                                                                                                                                                                                                      |
| `0x47`                                 | —                       | set `0x4000`                            | not identified                                                                                                                                                                                                                                                        |
| `0x48`                                 | —                       | `0x10000` / `0x8000`                    | wrap addressing                                                                                                                                                                                                                                                       |
| `0x49`                                 | —                       | `0x8000` / `0x10000`                    | clamp addressing                                                                                                                                                                                                                                                      |
| `0x4a`                                 | —                       | set `0x20000`                           | not identified                                                                                                                                                                                                                                                        |
| `0x4b`                                 | —                       | `0x100000` / `0x80000`                  | not identified                                                                                                                                                                                                                                                        |
| `0x4c`                                 | —                       | `0x400000` / `0x200000`                 | not identified                                                                                                                                                                                                                                                        |
| other                                  |                         | error 0                                 |                                                                                                                                                                                                                                                                       |

Integer operands are stored as bytes (`& 0xff`). Byte `+0x23` is the destination blend index with flag `0x100` and the opacity with flag `0x1000`.
