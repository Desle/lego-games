# Cutscenes: what the player sees as a race and a circuit start and end

Source: `LEGORacers.exe` (English, 1999-07-22), decompiled, and the emulator's front end trace (`front_end_trace.py`). Names are in `reverse-engineering/names/LEGORacers.exe.txt`. A race folder holds no cinema file: the in-race cutscenes are camera work (the track world's camera bone, the finish preset) and the HUD; the full-screen cinemas (`MENUDATA\CIRCUIT*`, `C_AWARD*`, `WIN*CAR`) belong to the front end.

## The circuit introduction

- `PickRacer_Leave` (`0x004850a0`, case `0x41`): with mode 0 (circuit) and one player picked, it pushes `0x1f + 0x0041f400(circuit)` (the circuit's index in `LEGORACE.CRB`, 0 for an unknown name) and leaves the front end running; otherwise it ends the front end (`front end +0x10 = 0`), which starts the race. Either way `0x004861b0` then pushes `saveall` (`0x30`) unless it is already on top.
- `saveall` (class `0x00486b30`) pops itself in its first update when no dialog is open (`0x00487020`). The front end keeps one screen object, for the top of the stack, so the introduction is made again when `saveall` goes: traced, the push is in frame 408, the pop in 409, nothing is drawn in 409 and the cinema's first update is in 410.
- The introduction (circuits 1 to 6: class `0x00479a80`; the seventh, `0x25`: the award class) loads its cinema and sets the music (`0x00479b10`). Its update (`0x00480b50`, `0x00476ad0`, then `CinemaScreen_Update` `0x00479a10`) takes the way out when the cinema widget is finished (`+0x630`, the widget's `+0x2c8`). The way out (`0x00479d10`; `0x00476a00` with the front end still running) pops it and ends the front end: the circuit's first race starts.
- The cinema widget's update (`Cinema_Update` `0x00466d90`) sets finished when it finds the record's end flag, which the clock (`CinemaTimeline_Update` `0x00406390`) set in the update before: the frame is `(rate × summed milliseconds) / 1000` and a frame at or past the length sets the flag. With 33 ms frames `CIR1-01` (490 frames at 30 per second) ends in frame 905, 496 updates after 409.
- **Skipping** (`CinemaWidget_OnKeyPress` `0x00466ec0`): a press (not a repeat, `+0x0d`) of device class 1, 2 or 3 finishes a skippable widget (`+0x2cc`, set by `0x00466b10`) once the record's frame (`+0x48`) has reached its rate (`+0x58`): one second in. The dispatch (`WidgetManager_DispatchEvents` `0x004692b0`) keeps up, down, tab, control and shift for the focus, so they never skip. Traced: enter, escape, space, A, F1, left, right and the keypad's enter skip in frame 440 and later, not in 439; up, down, tab and control never do.

Port: `pick-racer-screen` (the push), `save-all-screen`, `circuit-introduction-screen`, `stepFrontEnd` (`saveall` popped with the clocks of the screen under it at zero; the cinema input of `getCinemaScreenInput`, the same for every full-screen cinema), `cinema-clock` (`stepCinemaClock`, `getIsCinemaFinished`, `getIsCinemaSkipped`; `cinema-clock.differential.spec.ts` against `0x00406390` and `0x00466ec0`). `circuit-start.golden.spec.ts` runs the original front end through the racer pick and compares the screen stack: the push of the introduction and `saveall` (408), `saveall` gone (409), the end (905), a skip in 440 (the port gets keys one frame late, so 441) and none for enter in 439, down and up. The pixel trace's "Circuit start introduction" case reaches the cinema with the keys.

The racer pick's reaction clip now plays for the frame of the key (`startRacerShowcaseReaction`): without it the port left the racer pick one frame after the original (409 against 408).

**Not ported:** what `saveall` saves and its two draws in its frame; the cinema events' sounds (`bird2.pcm`, `ocean2.pcm` ... loaded with the introduction), fades and captions (at frame 880 the original draws the closing picture at about a third of the port's brightness).
