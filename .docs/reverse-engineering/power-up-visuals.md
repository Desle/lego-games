# Power-up visuals: what the original draws, against the port

`pnpm run render-trace` has sixteen power-up cases (`Royal Knights, power-up <kind> <brick>/<level>`: cannon `1`, shield `2`, turbo `3` and oil `4`, each at levels 0 to 3; RACEC0R0; the player is granted the brick at frame 300 and presses use at 305; frames 307 to 385). Run one with `pnpm --filter @lego-games/lego-racers-web exec vitest run --config vitest.trace.config.ts render-trace -t "power-up shield 2/0"` (`RENDER_TRACE_FRAMES=312` records one frame, `RENDER_TRACE_GROUPS=<file>` writes the mismatch groups).

The library the models come from is `GAMEDATA\COMMON\POWERUP.WDB`: its mesh and skeleton instances are what the exe looks up by name (`FUN_004119a0`): `Explsn` (mesh `hedra01`), `barrel`, `spikexp`, `warpprt` (mesh `warphole`), `magnet`, `TurboL0..2`, `turb0f1..2f2`, `dmissil`, `shield0..3`, `shldin0..3`, `curse`, `cgreen`, `magring`, `insd`, bricks. Keyword `0x3f` of an instance is the texture scroll per second (`warpprt` 3, 2; `shield0..3` and the first flame 0, 4; the second flame 0, 2). Textures and materials come from the libraries `DTURBO0..2`, `POWERUP`, `GRAPPLE`, `WARPHOLE`, `CURSE`, `BARREL`, `CGREEN`.

The presentation traces' race draws the racing tune (the emulator answers `DirectSoundCreate`), so the harness no longer sets `musicTuneCount: 0`; before, the port's random cursor ran one behind and every jitter was misplaced.

## Not ported (open)

- **Debris bricks (`brick1..4`, `0x004514b0`, `0x004515d0`)**: not drawn. The piece's figure takes the model, the attachment slot, a position (stack argument 2) and a first axis (argument 3, third axis up) and clip `thrownCount % clipCount`; no sampled frame shows a piece (frames 492 to 520 of `Royal Knights, debris` have pieces far from the camera), so there is nothing to verify against.
- **Effect emitters**: the cannon's and grapple's `cannsmk` follow the owner (above); `dynsprk`, `lghthit`, `oilbub`, `trbsmke` (`0x0045ce20`) are still never positioned.
- **Spiked explosion**: drawn (`spikexp`, scale and opacity as the plain one) and equal to the original's triangles on `Royal Knights, barrel explosion` (frames 388 to 430). Its flash (`exflash`) is not created by `0x00421250` for these pools and its scar (`exscar`) is a decal (another branch).
- **Cannon and rocket trails (`canstrk`, `mslstrk`)** are skid-trail decals (another branch).
- The shield's starting and ending alpha (`0x0045c2a0`) is not ported; the turbo's level-2 ending frame 355 still differs by about 3 pixels (the car turns).
