# The random table (`0x004befec`, position `0x004c6ee4`)

Source: `LEGORacers.exe` (English, 1999-07-22). Every site below was read in the disassembly (`DisassembleRange.java` and a per-function variant), not only the decompiler. The port lives in `packages/lego-racers/src/modules/random-table`.

## The table and the position

- `0x004befec` (`.data`, file offset `0xbefec`): 1,024 little-endian `uint16` values, each 0..1023 (659 distinct values; not a permutation). The port reads them from the player's own `LEGORacers.exe` through the PE section table (`readPortableExecutableBytes`, `loadRandomTable`); the table is never committed. Its SHA-256 (2,048 bytes) is `dc18033635bc1006b0e41d0bb8bed342d554ee0bbf29589d50b35aa000a952d5`, checked by the real-file spec.
- `0x004c6ee4` (`uint32`): the position. No code resets it: it starts at 0 (RVA `0xc6ee4` lies past the raw data of `.data`, so it is zero-filled) when the process starts and only ever advances, in the menus too. A server must send it at race start (`RandomTablePosition`, a plain integer 0..1023).
- `rand` is not imported and `srand` receives the address of the `timeGetTime` import (see game-map.md, Determinism): this table is the game's only randomness.

## How the code reads it

There is no random function: every read is inlined, always in this shape:

```
MOV EAX,[0x004c6ee4]          ; or MOV ECX/EDX
INC EAX  (or LEA EAX,[r + 1])
AND EAX,0x3ff
MOV [0x004c6ee4],EAX          ; sometimes after the read, never skipped
MOV DX,word ptr [EAX*2 + 0x004befec]   ; into a register zeroed by XOR first
```

The position advances **before** the read. What follows the read is one of these forms (all ported):

| Form         | Instructions                                                                                                                                                                               | Port                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| Value        | `MOV r16,word ptr`                                                                                                                                                                         | `drawRandomValue`                                                                         |
| Remainder    | `DIV`/`IDIV` by a constant or a field; `AND r,0x80000001` / `0x80000003` / `0x80000007` (the compiler's signed `% 2`, `% 4`, `% 8`); identical results because the value is never negative | `drawRandomRemainder` (a divisor of 0 raises `#DE` in the original: `RandomDivisorError`) |
| Low byte     | `MOV r8,byte ptr` then `AND r,0xff`, compared with a byte chance                                                                                                                           | `drawRandomLowByte`                                                                       |
| Bit test     | `TEST byte ptr [..],0x2`, `SHR`+`AND 1`                                                                                                                                                    | `drawRandomValue` and the caller's mask                                                   |
| Scaled range | range `< 0x400`: `value % range`; else `(range / 1023) * value`, the division by the magic multiplier `0x401005`                                                                           | `drawRandomScaledRange`                                                                   |
| Linear       | `LEA r,[value*8 + 0x7d0]`, `LEA r,[value*4 + 0x1388]`, `FILD` then `FMUL`                                                                                                                  | the caller (racer-ai)                                                                     |

Four functions (`0x00453240`, `0x0045b550`, `0x004572a0`, `0x0048f5b0`) compute the second position from the first in a register and store only once; the result equals two consecutive draws.
